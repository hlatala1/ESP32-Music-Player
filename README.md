# ESP32 Music Player

An object-oriented music player based on ESP32.

## Project description
The goal is to develop a portable music player
using an ESP32 microcontroller and C++.

## Planned features
- Music playback from microSD card
- OLED display interface
- Rotary encoder navigation
- Playback controls
- Bluetooth audio support (planned)

## Technologies
- C++
- ESP32
- Arduino framework
- PlatformIO

## Project milestones
- v0.1.0 - Basic player functionality
- v0.2.0 - User interface and playback controls
- v1.0.0 - Complete tested release

## Inspiration
Inspired by Huy Vector's ESP32 Music Player:
